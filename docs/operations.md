# 日常操作与维护

线上地址：[想看清单](https://austinzheguo.github.io/wishlist/)。网页由 GitHub Pages 托管，数据保存在 Supabase；当前采用**公开可编辑**模式，不需要登录。

## 日常使用

- 添加、编辑、删除以及导入后，右上角会显示“等待同步”“正在同步”或“已同步”。看到“同步失败”时，修改仍保存在当前浏览器；恢复网络后点击“重试同步”。
- 在另一台设备使用前，等待当前设备显示“已同步”再切换，避免较旧的整份清单覆盖新内容。
- 每月一次、以及调整数据库权限前，在网页右上角点击“导出备份”，将 JSON 文件至少保存在本机和一个云盘位置。

## 更新网页

正式源码在本仓库的 `index.html`。修改与发布流程：

1. `git pull` 获取最新版本。
2. 修改并在本地测试；不要直接编辑旧资料目录里的 `wishlist.html`。
3. 用 `git diff` 核对改动，然后提交并 `git push`。
4. 等 GitHub Pages 部署完成后，用无痕窗口打开线上地址确认。

## 安全与恢复密码

公开模式意味着知道网址的人都能查看、添加、编辑和删除这份清单。Supabase 的 publishable key 可以公开，但绝不能把 `service_role`、secret key、数据库密码或账号密码写入仓库。

如需重新启用密码访问，请按 [public-mode.md](public-mode.md) 的“以后恢复密码”部分操作；恢复前先导出一份备份。
